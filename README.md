# Draw3D  
A browser-based 3D drawing application built with Three.js.  
Designed to run smoothly on desktop and mobile, and fully compatible with GitHub Pages.

---

## ✨ Features
- 3D drawing using raycasting  
- Adjustable brush size  
- Color picker  
- Undo / redo  
- Clear canvas  
- Orbit camera controls  
- Mobile-friendly touch support  
- Lightweight and fast — no backend required
